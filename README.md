# CCP-Assure demo

A local-data, design-time cyber-assurance demonstrator for an illustrative cFS-style reference satellite.

- `index.html` is the interactive system view, attack graph, and step-through simulation.
- `assurance-review.html` is the companion ranked-path/evidence report.
- `examples/grounded/SOURCES.md` records the supplied grounding and its citation limitations.

This is not an operational digital twin. It has no live telemetry, spacecraft connection, onboard agents, or recovery control. Attack paths are the cheapest routes found in the hand-authored technique library. Costs are not probabilities. SPARTA identifiers remain marked unverified; NIST control associations are indicative; SPACE-SHIELD is unmapped. Confirm the exact citations before presenting the supplied evidence as authoritative.

All browser behavior and data are embedded in the static pages. No application server or runtime network connection is used.
