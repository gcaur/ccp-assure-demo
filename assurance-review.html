Baseline result · five cost-ranked paths

Uniform-cost search returns the cheapest path found in the hand-authored technique library for each reachable failure mode. Cost represents attacker difficulty, not probability.

AP-1 · FM-05 highcost 2
Uplink flooding (cyber DoS)
SPARTA EX-0013.01 · unverified NIST indicative · SPACE-SHIELD unmapped
Derived requirement: To prevent FM-05 ("Denial of mission service (loss of availability) - cyber, RF or kinetic") via path AP-1, the system shall implement: Uplink rate-limiting / filtering; Link-layer authentication.
T-uplink-flood · inspect model, evidence and indicative alignment

Model rule: Flood the command uplink to deny legitimate commanding (cyber-induced).

PUB-dos (published_vuln, high confidence): Link jamming/flooding and onboard resource exhaustion are established denial vectors. The 2022 ViaSat/KA-SAT incident (24 Feb 2022, AcidRain wiper via the ground/management network) bricked tens of thousands of modems across Europe — a real ground-segment-to-service denial (SPARTA EX-0013 Flooding, EX-0016 Jamming; cf. IA-0007 Compromise Ground System).

Supplied source note: ViaSat public statement (Mar 2022); SentinelLabs AcidRain analysis; EU/US attribution May 2022

Indicative countermeasures: Uplink rate-limiting / filtering; Link-layer authentication

Indicative NIST IDs: SC-5 (not a certified crosswalk)

AP-2 · FM-03 highcost 3
GNSS / GPS spoofing
SPARTA EX-0014.04 · unverified NIST indicative · SPACE-SHIELD unmapped
Derived requirement: To prevent FM-03 ("Loss of navigation / timing integrity (GNSS spoofing)") via path AP-2, the system shall implement: GNSS authentication (e.g. Galileo OSNMA); Multi-sensor navigation cross-check.
T-gnss-spoof · inspect model, evidence and indicative alignment

Model rule: Transmit counterfeit GNSS signals to corrupt the spacecraft's position/timing.

PUB-gnss-spoof (published_vuln, high confidence): GNSS/GPS spoofing is well-documented; counterfeit signals corrupt position and timing. Real-world maritime/aviation spoofing observed (e.g. Black Sea anomalies, 2016+) (SPARTA EX-0014.04 PNT Spoofing).

Supplied source note: GNSS spoofing literature; UT Austin spoofing demonstrations; add citation

Indicative countermeasures: GNSS authentication (e.g. Galileo OSNMA); Multi-sensor navigation cross-check

Indicative NIST IDs: SI-4, SC-16 (not a certified crosswalk)

AP-3 · FM-04 highcost 4
Downlink telemetry spoofing
SPARTA EX-0014 · unverified NIST indicative · SPACE-SHIELD unmapped
Derived requirement: To prevent FM-04 ("Operators / twin act on a false situational picture (telemetry spoofing)") via path AP-3, the system shall implement: Authenticated commanding (signed telecommands); Authenticated / signed telemetry.
T-telemetry-spoof · inspect model, evidence and indicative alignment

Model rule: Inject forged telemetry so operators / the twin act on a false situational picture.

PUB-tm-spoof (published_vuln, medium confidence): Unauthenticated downlink telemetry can be forged, feeding operators/the twin a false situational picture (SPARTA EX-0014 Spoofing).

Supplied source note: TT&C security literature; add citation

Indicative countermeasures: Authenticated commanding (signed telecommands); Authenticated / signed telemetry

Indicative NIST IDs: IA-2, SC-8, SC-16 (not a certified crosswalk)

AP-4 · FM-01 criticalcost 5
Forge / spoof an uplink command → Actuate effector via a forged command
SPARTA EX-0014 · unverified SPARTA EX-0012.07 · unverified NIST indicative · SPACE-SHIELD unmapped
Derived requirement: To prevent FM-01 ("Unauthorized actuation of an effector (e.g. thruster)") via path AP-4, the system shall implement: Authenticated commanding (signed telecommands); Authenticated / signed telemetry; Independent actuation authorization; Command arming / two-step effector enable.
T-cmd-spoof · inspect model, evidence and indicative alignment

Model rule: Craft a forged telecommand accepted as genuine due to weak/absent authentication.

PUB-cmd-auth (published_vuln, high confidence): Weak/absent uplink command authentication enables replay and forgery. Documented TT&C weakness class; many legacy spacecraft lack authenticated commanding (SPARTA EX-0001 Replay, EX-0014 Spoofing).

Supplied source note: SPARTA matrix (aerospace.org/SPARTA); CCSDS SDLS motivation; add primary citation

Indicative countermeasures: Authenticated commanding (signed telecommands); Authenticated / signed telemetry

Indicative NIST IDs: IA-2, SC-8, SC-16 (not a certified crosswalk)

PUB-cmd-auth (published_vuln, high confidence): Weak/absent uplink command authentication enables replay and forgery. Documented TT&C weakness class; many legacy spacecraft lack authenticated commanding (SPARTA EX-0001 Replay, EX-0014 Spoofing).

Supplied source note: SPARTA matrix (aerospace.org/SPARTA); CCSDS SDLS motivation; add primary citation

Derived requirement: To prevent FM-02 ("Arbitrary code execution on the OBC") via path AP-5, the system shall implement: Authenticated commanding / anti-replay counters; Session authenticity (sequence/time nonces); Input validation / memory-safe parsing; Fuzz-tested command paths.

Model rule: Crafted CCSDS/CFDP PDU the parser mishandles, yielding OBC code execution.

PUB-cfs-parser (published_vuln, medium confidence): Memory-safety flaws in flight-software packet/file parsers are a recognized class; demonstrated repeatedly in the Hack-A-Sat CTF (DARPA/US Space Force, 2020-2023) against NASA cFS-style stacks (SPARTA EX-0009 Exploit Code Flaws).

Supplied source note: Hack-A-Sat writeups; cFS security research; add exact reference

Indicative countermeasures: Input validation / memory-safe parsing; Fuzz-tested command paths

Implemented versus planned

implemented

  • Five input/output contract schemas and cross-reference validation.
  • JSON and HTML assurance report with derived requirements.

Grounding and assurance caveats

  • Target is an illustrative cFS-style reference satellite, not a real mission or customer system.
  • SPARTA identifiers are transcribed from the public matrix but remain unverified against the authoritative STIX export; each retains sparta_verified: false.
  • NIST control associations are indicative engineering judgment, not a certified crosswalk. SPACE-SHIELD is not mapped (SS-NOT-MAPPED).
  • Evidence records contain source summaries; the supplied provenance note says exact citations must be checked before external publication.
  • The before/after result demonstrates sensitivity to an explicit rule-suppression assumption. It does not prove authentication implementation effectiveness.

Supported claim: repeatable, cost-ranked path search over known techniques, with traceable report output and a design-time what-if. This is not unknown-unknown discovery or operational cyber defence.
